# Reviewed releases and optimization trials

This directory stores compact sign-off reports, complete cycle CSVs, and
documented rejected experiments. It is evidence, not a compile input.

- `*_SIGNOFF_*.md`: retained checkpoint or infrastructure sign-off.
- `*_TRIAL*.md` and `*_STUDY*.md`: measured experiment; not necessarily active.
- `*_k_sweep_*.csv`: per-case/per-algorithm cycle evidence.

The current authoritative pair is
`TOPK_APPEND_ACK_CHAIN_SIGNOFF_20260817.md` and
`topk_append_ack_chain_k_sweep_20260817.csv`. See the parent `reports/README.md`
for the retained/rejected index and `docs/PROJECT_STATUS.md` for the full
project inventory.
