# Archived material

This directory contains tracked historical material that is not part of the
active v2 build or paper flow.

- `v1/rtl`, `v1/verification`, `v1/sw`: frozen v1 snapshot and matching data.
- `research/`: exploratory benches, numerical studies, and paper drafts.
- `fpga/`: placeholder for older board/platform notes.

New RTL, testbenches, software, or golden data must not be added here. Use the
active top-level directories and the canonical v2 manifests instead.
