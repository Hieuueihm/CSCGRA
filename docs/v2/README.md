# RTL v2 documentation

RTL v2 is the active strict-PE0, four-row, factor-reuse implementation. The
old `CSCGRA_opt_architecture_opt2/CSCGRA.srcs` layout described in historical
documents is no longer authoritative; maintained RTL is under `rtl/v2`.

Read in this order:

1. `../PROJECT_STATUS.md` for current metrics and the complete optimization
   inventory.
2. `../CONTINUATION.md` for chronological checkpoints and the next candidate.
3. `FACTOR_REUSE_CORRECTNESS_REPORT.md` for the original factor-reuse baseline.
4. `ARCHITECTURE_PIPELINE_NOTES.md` for detailed pipeline notes.
5. `OPT2_PROGRESS_REPORT.md`, `OPT2_RELEASE_REPORT.md`, and
   `REFACTOR_REPORT.md` only as historical snapshots of earlier layouts.

Current release-quality sign-offs and cycle matrices are under
`reports/releases`; the latest is
`TOPK_APPEND_ACK_CHAIN_SIGNOFF_20260817.md`.
